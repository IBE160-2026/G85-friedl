# Statuslinje

## 2026-11-02 kl. 15:37 — Simon Friedl

### Oppgave
Brukeren ville ha mer info i Claude Codes statuslinje («hotbaren»): modell + effort (f.eks. «Opus 5.5 high»), hvor vi er, branch og bruksgrenser (tokens og 7-dagersgrensa).

### Plan
- Skrive et statuslinje-skript som leser JSON-input fra Claude Code med `jq`.
- Registrere det som `statusLine` i den globale `~/.claude/settings.json`.

### Resultat
- Ny fil `~/.claude/statusline.sh` (utenfor repoet, globalt for alle prosjekter). Viser: modell, effort, mappenavn, branch (`*` ved ukommitterte endringer), kontekstbruk i % og tokens, 5-timersgrense i %, 7-dagersgrense i % med tidspunkt for reset. Prosentene fargelegges grønn/gul/rød (<50/50–80/≥80).
- `~/.claude/settings.json` fikk `statusLine: { type: command, command: ~/.claude/statusline.sh }`.
- Testet med eksempel-input: `Opus 5.5 high | 📁 turplanlegger-Nettside | 🌿 main | ctx 23% (47k/200k) | 5t 12% | 7d 61% (reset Sun 15:53)`.
- Merk: statuslinjen får ikke vite hvilken fil som er åpen i editoren, så mappenavnet vises i stedet. Effort og grensene vises bare når Claude Code sender dem i input (grensene kun for Pro/Max-abonnement); skriptet faller ellers tilbake til `effortLevel` i settings eller skjuler feltet.
- Ingen endringer i repoet utenom denne loggen.
