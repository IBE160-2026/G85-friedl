# README: lokal kjøring og API-nøkler

## 2026-11-20 kl. 12:13 — Simon Friedl

### Oppgave
Læreren krever at README.md beskriver hvordan man kjører appen lokalt, og hvilke API-nøkler som trengs. Simon ba om en sjekk av at README dekker `ANTHROPIC_API_KEY` (hvor man får den, at den legges i `.env.local`, og at Demomodus virker uten), MET/Yr og Kartverket, og om å rette det som mangler og pushe.

### Plan
- Sammenlign README med koden: `src/server/miljo.ts` (nøkkelen), `src/server/vaer/met.ts` (User-Agent), `.gitignore` og `.env.example`.
- Skriv om «Kom i gang» og legg til en egen del om nøkler og tjenester.

### Resultat
- Dette manglet:
  - hvor nøkkelen lages
  - at den legges i `.env.local` (kopi av `.env.example`), og at serveren må startes på nytt
  - en tydelig setning om at Demomodus virker uten nøkkel
- README sa også at nøkkelen «bare settes i Production», noe som motsa lokal bruk.
- Ny del «API-nøkler og eksterne tjenester»:
  - en tabell over Anthropic (valgfri nøkkel), MET Norway (Locationforecast, samme data som Yr, ingen nøkkel, krever User-Agent) og Kartverket (ingen nøkkel)
  - trinn for `ANTHROPIC_API_KEY`
  - hva som skjer uten internett
- «Språkmodellteksten» viser nå til den nye delen.
- Commit `9deb1a4` er pushet til `main`. Ingen tester leser README.
