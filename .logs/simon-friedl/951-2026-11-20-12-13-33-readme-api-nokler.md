Læreren krever at README.md beskriver hvordan man kjører appen lokalt, og hvilke API-nøkler som trengs. ### Resultat
- Dette manglet:
  - hvor nøkkelen lages
  - at den legges i `.env.local` (kopi av `.env.example`), og at serveren må startes på nytt

- README sa også at nøkkelen «bare settes i Production», noe som motsa lokal bruk.
- Ny del «API-nøkler og eksterne tjenester»:
  - en tabell over Anthropic (valgfri nøkkel), MET Norway (Locationforecast, samme data som Yr, ingen nøkkel, krever User-Agent) og Kartverket (ingen nøkkel)

  - hva som skjer uten internett

- Commit `9deb1a4` er pushet til `main`. Ingen tester leser README.
